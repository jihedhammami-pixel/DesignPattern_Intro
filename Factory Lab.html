Two-minute recap

Factory Method: a base class (the creator) calls an abstract createX() method inside its own logic. Each subclass overrides it to return one concrete product.

Abstract Factory: an interface with one create method per product type. Each implementation creates one complete, matching family. The client receives the factory and asks it for products.

The cost: a new family is cheap; a new product type means editing every factory.
